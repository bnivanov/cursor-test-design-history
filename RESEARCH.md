# Movement research

Facts for catalog copy. Dates and examples are public history. Visual language is a working description, not a token file. Token values wait for the synthesized types.

Overlaps are real. Flash and Web 2.0 ran in parallel. Brutalism and Material ran in parallel. Records are movements, not exclusive decades.

## 1. Proto-web (1991-1995)

The web as a document. Tim Berners-Lee's CERN page (info.cern.ch, 1991) is text, default browser chrome, and blue links. NCSA Mosaic (1993) made inline images normal. Yahoo (1994) is a directory, not a composition. The first banner ad (AT&T on HotWired, 1994) arrives before layout as a craft.

Visual. Grey or white page. Times or browser default serif. Blue underlined links, purple visited. No grid. Images sit in the text flow.

Notable. info.cern.ch. Mosaic. Yahoo directory. HotWired.

## 2. Graphic vernacular (1995-1999)

Tables become a layout tool. Spacer GIFs hold columns. GeoCities (1994), Angelfire, and Tripod give millions of people a plot. Space Jam (1996) is still up. 88x31 buttons, hit counters, guestbooks, MIDI, tiled stars, "under construction."

Visual. Tiled backgrounds. Centered tables. Animated GIFs. Comic Sans, neon, bevels. 800-wide pages.

Notable. Space Jam (1996). GeoCities neighborhoods. The Hampster Dance (1998). Netscape.com.

## 3. Flash / skip intro (1998-2007)

Macromedia Flash makes the page a stage. Agency sites open with loaders and sound. "Skip intro" is the era's joke and its interface. 2Advanced and similar shops treat the browser as a director's tool. Steve Jobs's 2007 iPhone letter begins the end. Flash Player dies 31 Dec 2020.

Visual. Full-bleed animation. Timeline motion. Loading percentages. Custom cursors. No URL for inner states.

Notable. 2Advanced. Early Nike and agency portfolio intros. Gabocorp. YouTube's original player (Flash, 2005).

## 4. Web standards (2003-2006)

The Web Standards Project and Jeffrey Zeldman argue structure and presentation should split. CSS Zen Garden (Dave Shea, May 2003) proves one HTML file can wear many skins. Table layouts start to look like a hack.

Visual. Semantic HTML. CSS as the craft. Liquid or fixed but CSS-positioned. Typography experiments inside the Garden.

Notable. CSS Zen Garden. A List Apart. zeldman.com. Wired News redesign (Douglas Bowman, 2002).

## 5. Web 2.0 gloss (2004-2009)

O'Reilly's Web 2.0 (2004) names the product shift. Gmail, Flickr, Digg, Facebook, Twitter. AJAX. The look is candy: gradients, specular highlights, rounded rectangles, badges, reflections, "beta."

Visual. Glossy buttons. Blue and orange. Soft drop shadows. 960-ish width. Reflexive logos.

Notable. Original Gmail (2004). Digg. Flickr. Apple Web 2.0-era marketing pages. The "Web 2.0" logo generator culture.

## 6. Skeuomorphism (2007-2012)

The iPhone (2007) and iOS 1-6 teach software as physical object. Leather, felt, yellow legal pads, wooden shelves. The web follows Apple's product pages and dashboard widgets. Useful on a new touch screen. Heavy once people knew the gestures.

Visual. Textures. Stitching. Inner shadows. Analog controls. Rich lighting on UI chrome.

Notable. Apple.com product pages of the period. Find My Friends / Game Center language migrating to the web. Path. Early iCloud.com.

## 7. Responsive (2010-2014)

Ethan Marcotte, "Responsive Web Design," A List Apart, 2010. Fluid grids, flexible images, media queries. The Boston Globe (2011) is the first large news site to ship it. Bootstrap (2011) spreads a 12-column habit. Separate m. sites start to look dated.

Visual. Breakpoints. Hamburger as a compromise. Content reflow. Thumb-reach nav. One codebase.

Notable. ethanmarcotte.com / the ALA article. Boston Globe 2011. Bootstrap docs. The Guardian later RWD work.

## 8. Flat design (2012-2016)

Windows 8 Metro (2012) and iOS 7 (2013) strip texture. Medium and a generation of startups go bright fills, thin sans, and icons without bevels. Affordances get thinner. Speed and screen density are the excuse.

Visual. No skeuo textures. Primary color fields. Helvetica/San Francisco. Glyph icons. Plenty of air.

Notable. iOS 7 marketing on the web. Medium. Windows.com Metro era. Stripe's early simple pages.

## 9. Material Design (2014-2018)

Google I/O 2014. Paper, ink, elevation, motion as meaning. 8dp grid. Cards. Floating action button. A system, not a look. The web gets Material via Polymer and later Material Components.

Visual. Cards with rest elevation. Bold primary, accent ink. Meaningful motion. Bottom sheets and snackbars.

Notable. material.io. Recreated Google properties (Inbox, then Gmail). Polymer shop demos. Android web companions.

## 10. Brutalism / anti-design (2014-2020)

A reaction to Bootstrap sameness. Brutalist Websites (Pascal Deville) catalogs raw, ugly-on-purpose pages. Fashion and editorial (Balenciaga, Bloomberg Businessweek experiments, DIS) use collision, system fonts, and exposed structure as taste.

Visual. Default or mono type. Visible borders. Clashing sizes. Unbalanced layouts. "This is HTML."

Notable. brutalistwebsites.com. Bloomberg Businessweek digital experiments. Balenciaga.com of the period. It's Nice That when it goes raw.

## 11. Glass, dark, revival (2018-2023)

OS dark mode (macOS Mojave 2018, iOS 13 2019) makes OLED black a product choice. Glassmorphism (Big Sur, Fluent) is blur and translucency. Neumorphism is a short fad. In parallel, Y2K and maximalist revival (chrome, blobs, iridescence) reject the flat decade. Fashion e-comm and portfolios lead.

Visual. Backdrop-filter. Translucent bars. Soft light on dark. Or, conversely, chrome 3D, comic type, clutter.

Notable. apple.com Big Sur era. Microsoft Fluent web. Aries / SSENSE-adjacent fashion. Various Awwwards maximalist winners.

## 12. Spatial and agentic (2020-2026)

WebGL and Three.js become default for high-end marketing (Active Theory, Locomotive, Apple product films in-page). Scroll is a camera. Then ChatGPT (Nov 2022) and the agentic editor (Cursor, v0, Claude Artifacts) make chat and streaming the chrome. The page is a canvas a model fills.

Visual. Studio-lit 3D. Scroll-tied scenes. Then conversational layout, citation chips, split human/machine panes, token streaming.

Notable. stripe.com. apple.com product pages. activetheory.net. chatgpt.com. v0.dev. cursor.com.
